# 단어 온도계

비밀 단어 하나를 두고, 참가자가 아무 단어나 넣으면 비밀 단어와 얼마나 가까운지 온도(유사도)와 순위가 나옵니다. 가까운 단어를 따라가 비밀 단어를 맞히는 게임입니다.

## 유사도는 어떻게 계산하나요

- 미리 학습된 한국어 단어 벡터(spaCy `ko_core_news_lg`, floret 300차원, MIT 라이선스)에서 자주 쓰는 명사 약 2만 단어를 뽑아 `data/vec.bin`(int8, 6MB)과 `data/words.json`으로 넣었습니다. 서버나 AI 호출 없이 계산하므로 같은 단어는 언제나 같은 점수입니다.
- 비밀 단어는 **운영자 브라우저에만** 저장됩니다. 운영자 화면이 참가자의 추측을 받아 채점하고 결과만 돌려줍니다. 그래서 라운드 중에는 운영 노트북 화면이 켜져 있어야 합니다.
- 참가자 휴대폰은 단어 목록(약 200KB)만 받아, 목록에 없는 단어는 보내지 않고 바로 알려 줍니다 (횟수에 안 들어감).
- 순위는 비밀 단어를 뺀 약 2만 단어 중 몇 번째로 가까운지입니다. 1000위 밖은 "1000위 밖"으로 표시합니다.

## 진행

1. 로비의 **비밀 단어 정하기**에서 라운드별 정답을 넣습니다 (프로젝터에 비치지 않게, 기본은 가려 보임). **가까운 단어 보기**로 상위 20개를 확인하고, 엉뚱한 단어가 많으면 다른 정답을 고르세요. **추천 단어로 채우기**도 있습니다.
2. Enter: 라운드 시작 → 정답 공개 → 다음 라운드. H: 힌트(100위 → 30위 → 10위 단어를 차례로 공개). **1분 연장** 버튼.
3. 큰 화면에는 참가자별 가장 가까운 순위만 나오고 단어는 가립니다.

## 점수 (임시 규칙)

- 맞힌 순서대로 100, 98, 96 … 최소 50점
- 못 맞히면 가장 가까이 간 순위로 10위 안 30점, 100위 안 20점, 1000위 안 10점
- 동점이면 맞힌 라운드 수, 그다음 맞히기까지 걸린 시간 합이 짧은 순
- 3라운드, 라운드당 5분, 추측 무제한 (한 사람당 1.5초 간격)

설정값은 `common.js` 위쪽에 모여 있습니다.

## Firestore 사용량

추측 1번에 쓰기 2번(추측, 채점 결과)이 듭니다. 50명이 라운드마다 30번씩 추측하면 3라운드에 약 9천 번 쓰기로, 무료 한도(하루 2만)의 절반쯤입니다. 리허설은 행사 전날 이전에 하거나 짧게 해 주세요.

## 단어 목록 다시 만들기

`data/` 파일은 spaCy 모델의 벡터와 wordfreq 한국어 빈도 목록으로 만들었습니다. 단어를 추가하려면 같은 방식으로 다시 만들어야 해서, 필요하면 Claude에게 요청해 주세요.
